# (MVP 추가) 탐색 > 인플루언서 “일괄 추가(스프레드시트 입력)” 구현
중요:
- 기존 “새 인플루언서 추가(단일 입력)”는 유지하되, “일괄 입력(스프레드시트)” 모드를 추가한다.
- 파일 업로드 방식은 금지(이번 MVP 범위에서 Excel 업로드 import 제외).
- 사용자는 엑셀/스프레드시트에서 복사한 데이터를 그대로 붙여넣어 여러 명을 한 번에 생성할 수 있어야 한다.
- 커스텀 컬럼 난립 방지를 위해, MVP에서는 열(컬럼) 정의를 고정한다(템플릿 규칙 준수).
- UI 텍스트는 한국어.

────────────────────────────────────────
[1) 화면/UX]
대상: 탐색(Discover) > 인플루언서 > “새 인플루언서 추가” 플로우
- 상단 탭 2개 제공:
  A) 단일 입력(기존)
  B) 일괄 입력(스프레드시트) (신규)

일괄 입력 화면 구성:
- 상단 안내:
  - “엑셀에서 복사한 데이터를 그대로 붙여넣으면 여러 인플루언서를 한 번에 추가할 수 있습니다.”
- 스프레드시트 그리드(테이블) + 행 추가/삭제
- 하단 버튼:
  - [유효성 검사]
  - [일괄 추가]
- 결과 영역:
  - 성공 n건 / 실패 n건
  - 실패 행별 사유 표시

────────────────────────────────────────
[2) 그리드 컬럼(고정 템플릿, MVP)]
열 헤더와 순서(고정, 추가/삭제 불가):
1) 닉네임 (필수)
2) 플랫폼 계정 (필수)  예: @handle 또는 채널명
3) 플랫폼 (필수)  enum: Instagram / YouTube / TikTok / X / Blog (내부 표준값)
4) 팔로워 (선택, 숫자)
5) 컨택포인트 (선택)  예: 이메일/전화/카톡 등 문자열
6) 메모 (선택)
7) 단가 메모 (선택)  ← 기존에 추가한 priceMemo와 연결

※ “태그”는 사용하지 않음(제거 유지).
※ 정산정보(은행/사업자 등)는 이 일괄 입력 단계에서는 제외(또는 다음 단계에서 인플루언서 상세에서 입력).
   (MVP 단순화)

────────────────────────────────────────
[3) 엑셀 복사-붙여넣기 동작]
- 사용자가 그리드 셀을 선택한 상태에서 Ctrl/Cmd+V로 붙여넣으면,
  TSV(탭/줄바꿈) 데이터를 파싱하여 선택 셀 위치부터 행/열 방향으로 채운다.
- 데이터에 행이 더 많으면 그리드에 행을 자동 추가한다.
- 붙여넣기 시 열 개수가 7개를 초과하면 초과분은 무시한다.
- 붙여넣기 시 열 개수가 부족하면 남는 컬럼은 공백 처리한다.

────────────────────────────────────────
[4) 유효성 검증(필수)]
- 필수값 누락:
  - 닉네임, 플랫폼, 플랫폼 계정 중 하나라도 비면 오류
- 플랫폼 값 검증:
  - 허용 enum 외 값이면 오류(사용자에게 허용값 안내)
- 팔로워:
  - 숫자만 허용(쉼표/문자 포함시 자동 정규화 시도 가능, 실패하면 오류)
- 중복 체크(생성 전/후 모두):
  - (플랫폼 + 플랫폼 계정) 조합이 DB에 이미 존재하면 “중복”으로 오류 처리
  - 동일 입력 배치 내 중복도 감지

오류 UX:
- 오류 셀 붉은 테두리 + 툴팁 사유
- 하단에 “오류 리스트”로 행 번호/사유 요약

────────────────────────────────────────
[5) 일괄 생성 API]
- 프론트는 [일괄 추가] 클릭 시 서버에 batch create 요청을 보낸다.
- 권장 API:
  POST /api/influencers/batch
  body: { items: [{ nickname, handle, platform, followers, contactPoint, memo, priceMemo }, ...] }

서버 동작:
- 각 item별로 validate + 중복 체크
- 부분 성공 허용:
  - 성공: 생성
  - 실패: 해당 item은 skip하고 실패 사유 반환
response:
  { createdCount, failedCount, results: [{ index, status:'created'|'failed', reason? , influencerId? }] }

프론트 결과:
- 성공/실패를 행 단위로 표시
- “실패한 행만 남기기” 버튼(선택) 제공하여 수정 후 재시도 가능

────────────────────────────────────────
[6) 데이터 연결]
- “단가 메모”는 influencer.priceMemo 필드에 저장한다.
- “메모”는 기존 influencer.memo에 저장한다.
- “컨택포인트”는 influencer.contactPoint(또는 기존 필드)에 저장한다.

────────────────────────────────────────
[7) 완료 기준]
1) 엑셀에서 10행 데이터를 복사해 붙여넣으면 그리드에 10명이 채워진다.
2) [유효성 검사]에서 오류 셀/행이 표시된다.
3) [일괄 추가]를 누르면 부분 성공이 가능하며, 실패 사유가 행별로 나온다.
4) 생성된 인플루언서는 탐색 리스트에서 확인 가능하고, 단가 메모가 상세에 저장되어 있다.
