2) “대화 없음” 상태에서의 2가지 시나리오를 지원

사용자는 아래 2상황 중 하나임:
A) 플랫폼에서 아직 발송 안함 → 여기서 일괄 발송
B) 플랫폼 밖(기존 메일)에서 이미 연락함 → 그 스레드를 가져와서 이어가기

따라서 “대화 없음” 화면에 CTA 2개를 반드시 표시:

[일괄 발송]

[기존 메일 연결] (핵심)

3) 기존 메일 연결(Attach) 기능: “특정 메일/스레드”를 캠페인-인플루언서에 붙이기
3-1. 전제 조건 체크

연결된 이메일 계정이 없으면:

모달 안내: “이메일 계정이 연결되지 않았습니다”

버튼: [이메일 계정 연결하기] → Email Center로 이동(또는 같은 탭에서 연결 모달 오픈)

3-2. 연결 플로우(모달)

모달 제목: 기존 메일 연결

Step 1) 사용할 이메일 계정 선택 (Gmail/네이버/기타)
Step 2) 검색 방식 선택 탭

(추천) “상대 이메일로 찾기” → 인플루언서 email 자동 입력

“제목/키워드로 찾기”

“메시지 ID로 찾기(고급)” (옵션)

Step 3) 검색 결과 리스트(스레드 단위)

항목: 발신자/제목/최근 날짜/미리보기(1~2줄)

클릭하면 우측에 “전문 미리보기” (짧게)

선택 후 [이 스레드를 연결] 버튼

Step 4) 연결 완료

해당 스레드를 campaignId + influencerId에 attach

커뮤니케이션 탭 가운데 패널에 즉시 렌더링

토스트: “기존 메일을 연결했습니다”

4) 스레드 표현 방식(메신저형 + 전문 보기)
4-1. 기본 표시는 메신저형 버블

내 메시지 / 상대 메시지를 좌우로 구분

각 버블에는:

보낸 시간

제목(축약)

본문은 1~2줄만(ellipsis)

4-2. 전문 보기(클릭 시)

버블 클릭 → 오른쪽 or 가운데에 Drawer/Modal로 전문 표시

첨부파일이 있으면 링크/다운로드 표시(단순 표시만이라도)

5) 발송 작성 UX(플랫폼 내에서 계속 대화)
5-1. 작성창

가운데 패널 하단에 고정:

Subject 입력(기본값 자동 생성: “[캠페인명] 협업 문의”)

Body 작성(템플릿 선택 가능)

[보내기] 버튼

5-2. 템플릿(간단 버전)

템플릿 드롭다운 + 변수 치환:

{인플루언서이름}, {캠페인명}, {담당자명}

보내기 전에 미리보기

5-3. 보내기 후 처리

성공: 스레드에 즉시 추가 + 상태 “발송됨”

실패: 토스트 + 실패 사유 표시 + “재시도” 버튼

6) 수신 동기화(Reply를 플랫폼에서 보기)
6-1. 동기화 방식

커뮤니케이션 탭 상단에 버튼:

[메시지 동기화]

동기화 시:

선택된 계정의 IMAP(또는 Gmail API)에서 최신 스레드를 fetch

attach된 threadId에 매칭되는 새 메시지들을 DB에 저장 후 UI 반영

6-2. 자동 동기화(옵션)

MVP는 수동 버튼만

추후 cron job으로 N분마다 sync 가능하도록 구조만 준비

7) 이메일 계정 연동(최소 구현): Gmail + 네이버/기타

중요: 이번 작업에서 Email Center 전체 개편 금지.
단, “계정 추가” 버튼이 없어서 사용 불가하므로 계정 추가 버튼/모달만 추가한다.

7-1. Email Center에 추가할 것

좌측 Accounts 영역 상단에:

[+ 계정 추가] 버튼

7-2. 계정 추가 모달

Gmail: OAuth(가능하면), 아니면 “데모 모드(저장만)”라도 구현해 UI 흐름 막히지 않게

네이버/기타: SMTP/IMAP 입력 + “연결 테스트” 버튼

8) 데이터 모델(간단)

기존 DB가 무엇이든 상관없이 아래 개념만 충족:

EmailAccount (type: gmail|imap, smtp/imap settings, userId/workspaceId)

EmailThread (providerThreadId, campaignId, influencerId, emailAccountId)

EmailMessage (threadId, from, to, subject, snippet, body, date)

Influencer (email, memo, tags, phone, rate 등)

9) “클릭해도 변화 없음” 방지(필수)

리스트 아이템 클릭 시 반드시:

selected state 변경

가운데/우측 패널 내용 변경

로딩 스피너 표시

에러 시 토스트 출력

버튼(일괄 발송/기존 메일 연결/동기화/보내기) 클릭 시 반드시:

모달/드로어/토스트/스피너 중 1개 이상 UI 변화
