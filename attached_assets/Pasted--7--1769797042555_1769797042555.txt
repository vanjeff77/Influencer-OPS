[7] 현재 발견된 치명적 결함(반드시 해결) — “클릭해도 아무 변화 없음” 이슈
현 상태에서 아래 UI 인터랙션들이 동작하지 않는다(클릭/버튼 눌러도 변화 없음). 이는 “UI 이벤트 핸들러 미연결”, “라우팅 미구현”, “상태 관리 누락”, “API 호출 미연결” 중 하나 이상이 원인이다.
따라서 아래 항목을 최우선으로 디버깅하고, 동작하도록 구현하라. “보여주기 UI”가 아니라 실제 인터랙션과 데이터 저장까지 연결해야 한다.

A) Discover(탐색) > 인플루언서 카드/행 클릭 시 아무 변화 없음
필수 동작:
1) 리스트(카드/테이블)에서 인플루언서 클릭 → 반드시 상세가 열린다.
   - 방식은 아래 둘 중 하나로 구현(둘 중 하나는 반드시):
     (a) 오른쪽 패널(2-패널)로 상세 렌더링
     (b) Drawer/Modal로 상세 렌더링
2) 상세에는 최소 “기본정보/연락처/메모/태그/콘텐츠/타임라인” 탭(또는 섹션)이 있고, 수정/저장 가능해야 한다.
3) 클릭 시 URL 라우팅도 함께 지원:
   - 예: /discover?selected=<influencerId> 또는 /influencers/<id>
   - 새로고침해도 선택 상태가 유지되어 상세가 열린 상태로 복원되어야 한다.
4) 기술 요구:
   - onClick 핸들러 연결, 선택 상태(useState 또는 URL state), 데이터 fetch(useEffect 또는 서버 컴포넌트) 구현
   - API: GET /api/influencers/:id 호출 결과로 상세 렌더링

B) Campaigns(캠페인) > 캠페인 상세 클릭 후 “인플루언서 추가” 버튼 클릭해도 변화 없음
필수 동작:
1) 캠페인 카드 클릭 → 캠페인 상세 페이지로 라우팅 (/campaigns/<id>) 되거나 동일 페이지 내 상세가 열린다.
2) 캠페인 상세 내 “인플루언서 추가” 버튼 클릭 → 반드시 모달이 열린다.
   - 모달 기능:
     - 인플루언서 검색/선택(멀티)
     - 또는 “탐색에서 가져오기(그룹/필터)” 탭 제공(가능하면)
     - 확인 버튼 클릭 시 CampaignLineItem이 생성되어 라인아이템 테이블에 즉시 반영
3) 저장 동작:
   - POST /api/campaigns/:id/line-items (bulk add) 또는 /api/bulk/assign-to-campaign 호출
   - 성공 시 토스트 “추가되었습니다.”, 실패 시 “추가 실패” 표시
4) UX:
   - 이미 캠페인에 있는 인플루언서는 선택 불가 또는 중복 방지 경고

C) Groups(그룹) > 특정 그룹 클릭해도 아무 변화 없음(인플루언서 추가 불가)
필수 동작:
1) 그룹 리스트에서 그룹 클릭 → 그룹 상세 뷰가 반드시 바뀐다(우측 테이블 갱신 또는 /groups/<id> 라우팅).
2) 그룹 상세에는 “인플루언서 추가” 버튼이 있어야 한다.
   - 버튼 클릭 시 모달 열림(인플루언서 검색/선택 또는 CSV 업로드 탭)
   - 선택 후 저장하면 GroupInfluencer가 생성되어 테이블에 즉시 반영
3) 저장 동작:
   - POST /api/groups/:id/members (bulk add) 또는 /api/bulk/save-to-group 호출
4) 그룹 테이블 기능 최소:
   - 멤버 제거, 다운로드(필드 선택은 옵션), 컬럼 설정은 MVP 범위 내 구현

D) “아무 반응 없음” 방지용 필수 점검 항목(작업 순서에 포함)
1) 모든 주요 클릭/버튼에 대해 콘솔 에러/네트워크 요청 여부 확인:
   - 클릭 시 네트워크 요청이 0건이면 핸들러 미연결로 판단하고 즉시 수정
2) 라우팅/페이지 파일 존재 점검:
   - Next.js App Router 기준 /app/discover, /app/campaigns/[id], /app/groups/[id] 경로 구현 확인
3) UI 상태 업데이트 점검:
   - 모달 open state, selectedId state, table refresh(optimistic update 또는 revalidate) 구현
4) 실패 시 사용자 피드백:
   - 모든 API 실패는 한국어 토스트로 노출(조용히 실패 금지)

E) 완료 기준(상호작용 검증)
- Discover: 인플루언서 클릭 → 상세 열림(100% 재현 가능) + 메모 저장 후 새로고침해도 유지
- Campaign 상세: “인플루언서 추가” 모달 열림 → 2명 추가 → 라인아이템 테이블 즉시 반영
- Group 상세: 그룹 클릭 시 우측 테이블 변경 → “인플루언서 추가”로 2명 추가 → 테이블 즉시 반영
이 3개가 통과되지 않으면 MVP는 “동작하지 않는 UI”로 간주하며, 이를 최우선으로 수정한다.
