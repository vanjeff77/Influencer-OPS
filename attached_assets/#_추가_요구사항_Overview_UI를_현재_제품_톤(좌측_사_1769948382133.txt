# 추가 요구사항: Overview UI를 현재 제품 톤(좌측 사이드바 + 카드 UI + 넓은 여백)과 동일하게 구성

## 1) 레이아웃 고정
- 좌측 사이드바는 유지(변경 금지)
- 메인 컨텐츠는 "가로 최대 폭 1200~1400px" 느낌의 중앙 정렬 + 넉넉한 여백
- 섹션 간 간격은 24~32px 유지 (촘촘하지 않게)

## 2) 상단 배너(현재 유지 + 정보 보강)
- 배너 내부에 2줄:
  - 큰 타이틀: "다시 오신 것을 환영합니다, {사용자명}!"
  - 서브: "{진행 중 캠페인 n개} · {미응답 인플루언서 n명} · {오늘 마감 할 일 n개}"
- CTA 버튼 1개: "캠페인으로 이동" (기존 유지 가능)

## 3) KPI 카드 Row (필수)
- 5개 KPI 카드(필수 요구사항과 동일)
- 카드 디자인:
  - 좌: 아이콘(원형 배경)
  - 가운데: KPI 라벨(작게) + 숫자(크게)
  - 우상단: 작은 '>' 또는 클릭 힌트
- 카드 전체가 클릭 가능

## 4) 중단 2열: 좌(오늘의 할 일) / 우(요약 위젯들)
### 4-1) 좌: 오늘의 할 일(가장 큼)
- 카드 타이틀: "오늘의 할 일"
- 부제: "우선순위 기준으로 자동 정렬됩니다."
- 리스트 아이템 구성(한 줄 + 보조 정보):
  - [체크박스] 제목(1줄)
  - 우측: D-day 배지(예: D-0, D-1, D-3) 또는 '지연'
  - 아래 작은 글씨: 캠페인명 · 인플루언서명 · 현재 상태
  - CTA 버튼(작게): "바로가기"
- 빈 상태:
  - "오늘 처리할 할 일이 없습니다. 🎉"
- 최소 5개 이상 표시(더미 OK)

### 4-2) 우: 커뮤니케이션 요약 + 콘텐츠 현황
- 카드 2~3개 세로 스택
1) "커뮤니케이션 요약"
   - KPI: "새 답장 n건" / "미응답 n명"
   - 최근 스레드 5개(이름/캠페인/최근 시간/상태 배지)
   - CTA: "전체 보기"
2) "콘텐츠 진행 현황"
   - 상태별 카운트 4개(초안대기/피드백대기/업로드예정/업로드완료)
   - 클릭 시 해당 필터로 이동
3) (선택) "지급/정산 요약"
   - 지급대기 총액, D-3 임박 건수

## 5) 하단: 리스크&알림 + 최근 활동
- 좌: "확인 필요(리스크 & 알림)" 최대 10개
  - 배지: 오류/경고/임박/비공개
  - 한 줄 설명 + "열기" 버튼
- 우 또는 아래: "최근 활동"(기존 유지) + 더보기

## 6) 한국어 문구 톤
- 버튼: "이동", "전체 보기", "필터 초기화", "바로가기", "동기화" 등 간결한 한국어
- 상태 배지(예시):
  - 커뮤니케이션: 미응답 / 응답 / 발송 실패
  - 콘텐츠: 초안 대기 / 피드백 대기 / 피드백 전달 / 업로드 예정 / 업로드 완료
  - 정산: 지급 대기 / 지급 완료 / 보류

## 7) 동작 검증(추가)
- Overview 내 모든 카드/CTA는 "클릭 시 화면 변화"가 있어야 한다:
  - 페이지 이동, 탭 전환, 또는 필터가 적용된 리스트로 이동
- '오늘의 할 일' 체크는 새로고침 후에도 유지(localStorage OK)
