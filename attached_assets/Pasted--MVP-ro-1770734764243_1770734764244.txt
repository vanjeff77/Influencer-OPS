# (MVP) 인플루언서 행별 “상태형(단계형) 프로그레스 바” 구현 프롬프트 (컨택/확정 필수 조건 포함)
목표:
- 인플루언서 선정(리스트) 화면에서 각 인플루언서 행(row)마다
  진행 단계를 한눈에 보여주는 “단계형 프로그레스 바”를 표시한다.
- 프로그레스 바는 ‘표시’만이 아니라, “다음 단계로 전환”하는 컨트롤로 동작한다(Clickable Step Bar).
- 상태 전환 시 필수 입력 조건을 검사하고, 조건 미충족 시 상태 전환을 막고 안내 UX를 제공한다.
- UI 텍스트는 한국어.

────────────────────────────────────────
[1) 단계 정의(고정 순서)]
인플루언서 단계는 아래 순서를 따른다:

선정 → 컨택 → 확정 → 계약

내부 상태 enum 예시:
- SELECTED
- CONTACTED
- CONFIRMED
- CONTRACTED

────────────────────────────────────────
[2) 리스트(인플루언서 선정 메뉴) 행 UI 요구]
각 인플루언서 행에 다음 요소를 표시한다:
A) “단계형 프로그레스 바(클릭 가능)” (필수)
B) “현재 단계 텍스트 배지” (권장)

## 2-1. 프로그레스 바 UI 형태(컴팩트)
- 단계 라벨을 짧게 표시:
  선정 / 컨택 / 확정 / 계약
- 완료된 단계: 채워진 원(●) 또는 채워진 바
- 현재 단계: 강조된 원(◎) 또는 강조 바
- 미진행 단계: 비활성 원(○) 또는 점선 바

예시(텍스트 개념):
선정 — 컨택 — 확정 — 계약
 ●        ●        ◎        ○      

────────────────────────────────────────
[3) 상태 전환 로직(필수 조건 검사)]
프로세스:
1) 유저가 프로그레스 바에서 “다음 단계”를 클릭
2) 시스템이 해당 단계의 필수 조건을 검사
3) 조건 충족 → 상태 업데이트
4) 조건 미충족 → 상태 변경 차단 + 안내 UX 제공

────────────────────────────────────────
[4) 필수 조건 상세(요구사항 반영)]
## 4-1. 컨택(CONTACTED) 전환 조건
- 시스템은 “컨택 메뉴(커뮤니케이션/이메일)”에서
  해당 캠페인 + 해당 인플루언서에 연결된 이메일 스레드가 있는지 검사한다.

A) 이메일 스레드 내역이 존재하면:
- 즉시 CONTACTED로 상태 변경

B) 이메일 스레드 내역이 없으면(스레드 없음 또는 메시지 0건):
- 상태 변경을 바로 하지 말고 확인 모달을 띄운다.
- 모달 문구(정확히):
  “메일에 컨택내역이 없습니다. 컨택으로 기록할까요?”
- 버튼:
  [확인] / [취소]
  - “확인” 클릭 시:
    - CONTACTED로 상태 변경
  - 취소 클릭 시: 상태 변경 없음

## 4-2. 확정(CONFIRMED) 전환 조건(강제 입력)
- 확정 처리 전에 반드시 아래 2개 데이터가 입력되어야 한다:
  1) 광고료  2) 업로드 예정일

A) 두 값이 모두 입력되어 있으면:
- CONFIRMED로 상태 변경

B) 하나라도 없으면:
- 상태 변경을 차단하고 강제 안내를 표시한다.
- 안내 문구(정확히):
  “확정 처리 전 광고비와 업로드 일정을 입력해주세요”
- UX:
  - 확인 버튼만 제공


────────────────────────────────────────
[7) 완료 기준(테스트 시나리오)]
1) 리스트에서 각 인플루언서 행에 단계형 프로그레스 바가 보인다.
2) 현재 단계와 완료/미완료 단계가 시각적으로 구분된다.

4) 컨택 클릭:
   - 이메일 스레드가 있으면 즉시 컨택 처리된다.
   - 이메일 스레드가 없으면
     “메일에 컨택내역이 없습니다. 컨택으로 기록할까요?”
     모달이 뜨고 확인 시 컨택 처리된다.
5) 확정 클릭:
   - 광고비/업로드 예정일이 모두 있으면 확정 처리된다.
   - 없으면
     “확정 처리 전 광고비와 업로드 일정을 입력해주세요”
     메시지가 뜨고 입력 전까지 확정 처리되지 않는다.
