### 0-1. 구조 공식

```
[인사]     →  안녕하세요 {인플루언서명}님 / 밴스드 김주현입니다
[감사]     →  빠른 확인 감사드립니다! :)
[본문]     →  핵심 내용 (2~5줄)
[보조]     →  부가 안내 또는 향후 액션
[마무리]   →  편안한 하루 되세요 :) (선택)
[서명]     →  감사합니다 / 김주현 드림
```

## 3. PHASE 2 — 인플루언서 응답 분류 체계 (인바운드)

첫 번째 응답부터 협업 확정 직전까지, 인플루언서가 보낼 수 있는 모든 응답 유형을 분류합니다.

### 대분류 구조

```
인플루언서 응답
 ├── A. 단가/금액 관련 응답 (7개)
 ├── B. 협업 의사 표명 (5개)
 ├── C. 질문/정보 요청 (6개)
 ├── D. 역제안/조건 변경 (3개)
 └── E. 무응답/기타 (2개)
```

---

### A. 단가/금액 관련 응답 (7개 세부 케이스)

#### A-1. 고단가 회신 — PPL만 예산 초과
- **정의**: 인플루언서가 제시한 기본 PPL 단가 자체가 예산 상한선의 200%를 초과
- **실제 사례**: 김승영 1700만원, 제여비 600+250만원
- **감지 조건**: `추출금액 > 예산상한 × 2.0`
- **자동 판정**: → PHASE 3 **[R-1] 정중한 예산 거절**

#### A-2. 고단가 회신 — PPL+2차활용 합산 예산 초과
- **정의**: PPL 단가는 중간이나, 2차활용 등을 합산하면 예산 초과
- **실제 사례**: 김제법 750만/650만 + 2차 150만, 테디여행기 300만 + 2차 포함 500만
- **감지 조건**: `PPL단가 + 2차활용단가 > 예산상한 × 1.5`
- **자동 판정**: → **[R-1]** (다만 PPL만 150% 이내이면 → **[R-2]** 시도 가능)

#### A-3. 중단가 회신 — 소폭 초과 (네고 여지 있음)
- **정의**: 제안가 대비 +10~50% 수준이며, 인플루언서가 네고 의사를 직간접 표현
- **실제 사례**: 챙 60만원(제안 50만원), 디노 "150만원이나 120만원까지 협의 의사"
- **감지 키워드**: "희망", "조율", "가능할지", "협의 의사", "까지는"
- **감지 조건**: `제안가 × 1.1 ≤ 추출금액 ≤ 제안가 × 1.5`
- **자동 판정**: → **[R-2] 카운터 오퍼** 또는 → **[R-3] 소폭 초과 수락**

#### A-4. 적정 단가 회신 — 예산 범위 내
- **정의**: 제안가 이하이거나 동일한 금액을 회신
- **감지 조건**: `추출금액 ≤ 제안가 × 1.1` 또는 금액 미언급 + 수락 의사
- **자동 판정**: → **[R-3] 수락 확인 + 컨펌 대기 안내**

#### A-5. 구조화된 견적 회신 — 항목별 분리 제출
- **정의**: 인플루언서가 PPL/2차활용/부가세를 항목별로 정리하여 견적 전송
- **실제 사례**: 다은 "릴스 220만(VAT포함)/2차 3개월 70만/6개월 120만", 안될공학 "브랜디드 750만/쇼츠 150만/커뮤니티 50만"
- **감지 조건**: 2개 이상의 금액 + 항목 구분자
- **자동 판정**: 항목별 금액 추출 → 합산 비교 → 예산 범위에 따라 [R-1]/[R-2]/[R-3] 분기

#### A-6. 추가 비용 고지 — 촬영 관련 별도 비용
- **정의**: 해외 촬영비, 항공권, 출장비 등 콘텐츠 단가 외 별도 비용
- **실제 사례**: 다은 "해외 촬영 시 추가 비용 100만원(VAT 별도) 항공권 포함", 디노 "출장 발생 시 실비별도"
- **감지 키워드**: "추가 비용", "항공", "출장", "실비별도", "교통비"
- **자동 판정**: → **[R-4] 추가비용 확인 & 대안 제시**

#### A-7. 네고 역질문 — 거절 후 "얼마면 되나" 물어옴
- **정의**: 밴스드 거절 후, 인플루언서가 단가를 낮출 의사를 보이며 예산 역질문
- **실제 사례**: 웅진 "진행비는 협업가능합니다 혹시 클라이언트측에서 제시하는 금액은 얼마쯤인지요!"
- **감지 키워드**: "협업가능", "얼마쯤", "제시하는 금액", "예산이 어느정도"
- **감지 조건**: 이전에 [R-1] 거절 메일을 보낸 이력이 있는 스레드에서의 재응답
- **자동 판정**: → **[R-5] 구체 금액 카운터 오퍼** (거절→재오픈 전용)

### B. 협업 의사 표명 (5개 세부 케이스)

#### B-1. 즉시 수락
- **실제 사례**: 배꼬미올리 "제안주신 내용 확인하였으며 인스타 릴스 콘텐츠 협업 가능합니다"
- **감지 키워드**: "협업 가능", "진행하겠습니다", "진행 가능합니다", "가이드 전달해주시면"
- **자동 판정**: → **[R-3] 수락 확인 + 컨펌 대기 안내**

#### B-2. 관심 표명 — 긍정적이나 확답 아님
- **실제 사례**: 다해 "eSIM은 여행 콘텐츠와 궁합이 좋은 카테고리라 긍정적으로 검토하고 있습니다"
- **감지 키워드**: "긍정적으로 검토", "흥미", "관심", "좋은 제안"
- **자동 판정**: → 질문 유형 확인 후 **[R-6] 질문 답변** 조합

#### B-3. 조건부 수락 — "~하면 진행 가능"
- **실제 사례**: 다은 "릴스 1편 기준으로 진행 가능하며, 아래 조건으로 제안드립니다"
- **감지 키워드**: "조건으로", "~하면 진행", "단가 조율이 필요", "아래 조건"
- **자동 판정**: → 조건 내용 파싱 후 [R-2]/[R-3]/[R-6] 조합

#### B-4. 명시적 거절
- **실제 사례**: 산보노트 "Voye는 경험이 없어서 당장은 어려울 것 같습니다", 개발바닥 "잦은 채팅방 홍보는 불편해하실것 같다"
- **거절 사유 세분화**:
  - B-4a: 브랜드 미경험/미인지 → "경험이 없어서", "처음 들어봐서"
  - B-4b: 콘텐츠 방향 불일치 → "맞지 않", "다른 방향"
  - B-4c: 일정 불가 → "일정이 안 맞", "바빠서"
  - B-4d: 구독자 반응 우려 → "불편해하실", "잦은 홍보"
  - B-4e: 단순 사양 → "어렵습니다", "사양합니다"
- **자동 판정**: → **[R-7] 거절 수용 + 관계 유지**

#### B-5. MCN/소속사 대리 응답
- **실제 사례**: 로우프레임 이수연 (크리에이터 추천), 안될공학 모어사이언스 (정식 견적)
- **감지 키워드**: "자사", "전속", "운영사", "Partnership Manager", "소개서"
- **자동 판정**: → **[R-8] MCN 대응**

## 6. 멀티턴 시나리오 (PHASE 2<->3 반복 패턴)

### 시나리오 1: 오픈형 -> 고단가 -> 거절 -> 네고 -> 카운터 -> 합의

```
[OUT-A] 밴스드: "단가 문의드립니다"
  -> [A-5]  인플루언서: PPL 500만/브랜디드 850만 (구조화 견적)
  -> [R-1]  밴스드: "예산적인 부분의 한계... 어려울 것 같아 전달드립니다"
  -> [A-7]  인플루언서: "진행비는 협업가능합니다 제시하는 금액은 얼마쯤?"
  -> [R-5]  밴스드: "PPL 100만원 / 2차활용 30만원... 네고 가능하시라면 편히 말씀"
  -> [A-4 or B-1] 인플루언서: 수락 또는 2차 네고
  -> [R-3]  밴스드: "진행 시 {금액}으로 이해하겠습니다"
```

### 시나리오 2: 제안형 -> 소폭 초과 -> 수락

```
[OUT-B] 밴스드: "릴스 PPL + 2차활용 -> 50만원 제안드립니다"
  -> [A-3]  인플루언서: "60만원에 진행하기를 희망합니다. 조율이 가능할지"
  -> [R-3]  밴스드: "조정 가능하며 진행 시 60만원으로 이해하겠습니다"
```

### 시나리오 3: 관심 -> 질문 -> 답변 -> 단가 -> 수락

```
[OUT-C] 밴스드: "상세 브리프 + 단가 요청"
  -> [B-2+C-1] 인플루언서: "긍정적으로 검토... 국내/해외 어떤 형태?"
  -> [R-6+M-1] 밴스드: "해외 안 가도 됩니다 + 가이드 전달 예정"
  -> [A-3+A-6] 인플루언서: "릴스 1편 220만원, 해외 촬영 시 추가 100만원"
  -> [R-4a]    밴스드: "해외 촬영 계획 언제? + 방문도시/추가비용/초안일정"
  -> [A-6 상세] 인플루언서: "3월 초 후쿠오카, 추가 100만원, 3~5일 내 초안"
  -> [R-3]     밴스드: 수락 -> PHASE 4로
```

### 시나리오 4: MCN -> 예산 탐색 -> 대안 크리에이터 -> 거절/진행

```
[OUT-A]  밴스드: "우림이씨님 단가 문의"
  -> [B-5+A-5] MCN: 소개서 + 견적 + 추가 크리에이터 추천
  -> [R-8a]    밴스드: "예산 500만원, PPL+2차 75만원으로 가능한 분 3~4명?"
  -> [A-5]     MCN: "유어리아님 추천, 기본 100만원 내외"
  -> [R-8b]    밴스드: "예산 한계로 진행 어려울 것 같습니다"
```

### 시나리오 5: 거절 -> 관계 유지 (단턴 종료)

```
[OUT-A/B] 밴스드: 초기 컨택
  -> [B-4]    인플루언서: "Voye는 경험이 없어서 당장은 어려울 것 같습니다"
  -> [R-7]    밴스드: "말씀주신 부분 이해하였습니다! 더 좋은 협업건 있으면 제안드리겠습니다"
  -> (종료)
```
